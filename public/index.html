Google Search Console
用你自己的 Google 账号授权，数据直连。
  1. 打开 Google Cloud → 凭据，建一个 OAuth 客户端，类型选 Web 应用；并在「API 库」里启用 Search Console API。
  2. 把下面这个地址粘进「已获授权的重定向 URI」，保存后把 Client ID / Secret 填到下面。
http://127.0.0.1:4319/api/gsc/callback
只存在本机 data/gsc.json，不会上传。

Search Console →「效果」→「查询」，把整张表复制进来（制表符 / CSV 都行，中英文表头都认）。

阈值：第 11–20 名且展示 ≥50 → 临门一脚；前 10 名但 CTR<2% → 改标题；21–50 名 → 内容太浅；>50 名 → 没有内容
